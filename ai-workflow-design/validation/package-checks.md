# Проверки подготовленного пакета

Дата: 22 октября 2026. Проверяется комплект проектных документов, а не развёрнутая мультиагентная система.

## Выполненные проверки

- Проверка состава: восемь role prompts, общий prompt, два скилла, архитектура, права, контракты, профиль, сценарии и миграция.
- Итоговая локальная проверка: 26 файлов, 20 разрешённых локальных ссылок, ошибок структуры не обнаружено. ZIP содержит все 26 файлов; целостность архива проверена.
- Проверка десяти требуемых разделов в каждом role prompt; промпты и скиллы написаны на английском.
- Чтение файлов как UTF-8, проверка закрытых Markdown code fences и локальных ссылок.
- Разбор JSON schema и полного JSON-примера результата; проверка разрешения внутренних `$ref` схемы. Полноценный JSON Schema engine в окружении отсутствует; формальная валидация Draft 2020-12 здесь не заявляется.
- Прямая проверка полей `name`/`description` двух простых frontmatter, допустимых имён, ограничений длины и отсутствия незавершённых TODO. Это ограниченная проверка конкретных файлов, не универсальный YAML parser.
- Документальная сверка обязанностей, scopes, статусов, Red/Green, snapshot invalidation, formatter и model routing; результаты в design-review.
- Семь документальных симуляций, включая четыре обязательных сценария из ТЗ. Это моделирование, не исполнение Scala-тестов.

## Ограничения инструментальной проверки

Штатный `skill-creator/scripts/quick_validate.py` был вызван для обоих скиллов и завершился до проверки файлов с `ModuleNotFoundError: yaml`. Попытка установить PyYAML и jsonschema только в служебный каталог проверки не удалась из-за недоступного DNS для pypi.org. Рабочие конфигурации агентов при этом не менялись. Эти проверки не отмечены как passed.

Перед установкой на целевой платформе повторить штатную валидацию скиллов, разбор YAML профиля и проверку схемы полноценными средствами окружения. Профиль намеренно содержит `enabled: false` и незаполненные deployment-specific значения; это защищённый от случайного применения шаблон, а не незавершённые основные правила ролей.

Не выполнялись: реальная Scala compilation, tests и Scalafmt, запуск корпоративных моделей, импорт конфигурации в runtime, P01–P22 на целевой платформе. Следовательно, пакет готов для адаптации и пилота; гарантии технического enforcement должны быть подтверждены при внедрении.
